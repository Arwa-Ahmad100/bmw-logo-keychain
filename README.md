# BMW Logo Keychain

A parametric BMW-inspired keychain designed in **Autodesk Fusion** and prepared for 3D printing.

<p align="center">
  <img src="Images/BMW_Logo_Keychain.png" width="500">
</p>

## Project Overview

The model was created as a 2D sketch and converted into a 3D printable keychain using a parametric CAD workflow.

### Main Specifications

- Outer diameter: ~60 mm
- Thickness: 2 mm
- Keychain hole: 4 mm
- Single solid body
- Recessed details for easier hand painting
- Prepared for FDM 3D printing

## CAD Workflow

`Sketch → Dimensions → Extrude → Recessed Details → STL Export`
